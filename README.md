📝 Project Description
This project is a clean, responsive, single-page clone of the Udemy homepage. Built purely with semantic HTML5 and modern CSS3, it mimics the core visual styling and layout structure of the popular e-learning platform. The design captures the authentic Udemy user interface, utilizing custom styling, clean typography, and subtle micro-interactions to create an engaging user experience.

✨ Features
1. Header & Navigation Bar
Sticky Navbar: Remains fixed at the top of the viewport during scrolling for easy navigation access.

Search Functionality: An styled search bar complete with embedded icon styling.

Cart & Auth Actions: Features a stylized shopping cart component with an interactive items badge, along with sleek CTA buttons for "Log in" and "Sign up".

2. Layout & Organization
Category Menu Bar: A horizontal navigation menu representing different course streams (Development, Business, IT, Design, etc.) with custom hover states.

Hero Section: A rich gradient banner featuring promotional copy, an "Explore Now" call-to-action, and a statistic badge container detailing learner metrics.

3. Dynamic Grids & Content Components
Responsive Course Grid: Displaying realistic mock course cards populated with badges (e.g., Bestseller, Hot & New), dynamic thumbnail placeholders, author credits, star ratings, and price variations.

Interactive Topics Chip Component: A dedicated section displaying popular search tags (Python, React, AWS, etc.) optimized with modern hover transitions.

Multi-Column Footer: A clean, dark-themed footer displaying links organized into category columns, legal copy, and standard copyright statements.

4. Interactive Micro-UX (Vanilla JavaScript)
Visual Selection Feedback: Clicking on a course card highlights it temporarily with Udemy's signature purple border.

Topic Injection Mapping: Clicking on any topic chip automatically populates the text into the input field for a seamless user flow.

🛠️ Tech Stack
HTML5: Structured semantic markup (<header>, <nav>, <section>, <footer>).

CSS3: Vanilla styling utilizing Custom CSS Variables (Themes), Flexbox for custom positioning, CSS Grid for product alignments, and @media queries for custom desktop/mobile responsive breakdowns.

JavaScript: Vanilla JS for event handling, input binding, and dynamic component behaviors.
